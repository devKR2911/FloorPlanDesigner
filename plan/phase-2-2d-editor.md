# Phase 2: 2D plan editor

Status: not started. Needs its own go-ahead before work begins.

Back to the [project plan](project-setup-plan.md).

## Scope

A plan editor drawn on an HTML5 Canvas 2D element inside the engine library.

- Draw, move and delete walls.
- Snapping to the grid and to existing corners.
- Dimensions shown along walls.
- The engine takes a `view2d` element next to `view3d`.

The detailed plan is written when the phase is approved.
